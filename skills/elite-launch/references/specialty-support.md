# Specialty support router

Load only the specialist needed by the affected code. Do not preload the catalog.

| Need | Skill/source |
|---|---|
| Visual system, tokens, components, contrast, CSS, motion craft | `world-class-design` |
| Photos, icons, fonts, logos, illustrations, video, animation assets | `design-assets` |
| Responsive compact mobile layout | `responsive-mobile-compact` |
| Web tween/easing/responsive motion | `gsap-core` |
| Sequenced web motion | `gsap-timeline` |
| Scroll-linked web motion | `gsap-scrolltrigger` |
| React lifecycle and cleanup | `gsap-react` |
| Vue/Svelte/other framework lifecycle | `gsap-frameworks` |
| FLIP, drag, Observer, SplitText, ScrollSmoother, other GSAP plugins | `gsap-plugins` |
| Animation helpers | `gsap-utils` |
| Animation performance | `gsap-performance` |
| Rive or Flame runtime work | `interactive-animation-systems` |
| Current Laravel/Flutter/Dart/TypeScript/Python/Firebase/GCloud/AWS/payment/design-tool docs | `live-official-docs` |
| Apache Commons APIs and examples | `apache-commons-official-docs` |

Use Playwright or the available browser driver for the real running UI. Use the
project's formatter, linter, analyzer, typechecker, test framework, build system,
and platform profiler. A specialty tool informs the implementation; it never
expands prompt scope or authorizes another model, subagent, commit, push, deploy,
or security change.
