# Apache Commons Net official sources

Match the resolved `commons-net` version and JDK. Read the [project overview](https://commons.apache.org/proper/commons-net/) for supported protocols, the [current Javadoc](https://commons.apache.org/proper/commons-net/apidocs/) for exact signatures, and [security reports](https://commons.apache.org/proper/commons-net/security.html) before implementation. Use the [migration guide](https://commons.apache.org/proper/commons-net/migration.html) only when changing versions.

## Protocol examples

Open only the requested protocol group. Then return to its Javadoc package and apply the flow through the project's existing typed integration.

- SMTP/SMTPS — [SMTPMail.java](https://commons.apache.org/proper/commons-net/examples/mail/SMTPMail.java): connection, authentication, envelope, headers, body, reply handling, and disconnect flow.
- FTP/FTPS — [FTPClientExample.java](https://commons.apache.org/proper/commons-net/examples/ftp/FTPClientExample.java): upload, download, listings, modes, and FTPS branches. [ServerToServerFTP.java](https://commons.apache.org/proper/commons-net/examples/ftp/ServerToServerFTP.java): bounded server-to-server transfer flow.
- TFTP — [TFTPExample.java](https://commons.apache.org/proper/commons-net/examples/ftp/TFTPExample.java): UDP transfer direction, mode, timeout, and cleanup.
- NNTP — [ArticleReader.java](https://commons.apache.org/proper/commons-net/examples/nntp/ArticleReader.java), [ExtendedNNTPOps.java](https://commons.apache.org/proper/commons-net/examples/nntp/ExtendedNNTPOps.java), [MessageThreading.java](https://commons.apache.org/proper/commons-net/examples/nntp/MessageThreading.java), [PostMessage.java](https://commons.apache.org/proper/commons-net/examples/nntp/PostMessage.java), [ListNewsgroups.java](https://commons.apache.org/proper/commons-net/examples/nntp/ListNewsgroups.java): article read/post, authentication, overview, threading, and large listings.
- NTP/Time — [NTPClient.java](https://commons.apache.org/proper/commons-net/examples/ntp/NTPClient.java), [TimeClient.java](https://commons.apache.org/proper/commons-net/examples/ntp/TimeClient.java): UDP/TCP time queries, response fields, clock offset, and failure handling.
- Telnet — [TelnetClientExample.java](https://commons.apache.org/proper/commons-net/examples/telnet/TelnetClientExample.java), [WeatherTelnet.java](https://commons.apache.org/proper/commons-net/examples/telnet/WeatherTelnet.java): negotiation, streams, interactive I/O, and disconnect flow.
- Unix clients — [chargen.java](https://commons.apache.org/proper/commons-net/examples/unix/chargen.java), [echo.java](https://commons.apache.org/proper/commons-net/examples/unix/echo.java), [finger.java](https://commons.apache.org/proper/commons-net/examples/unix/finger.java), [rshell.java](https://commons.apache.org/proper/commons-net/examples/unix/rshell.java), [rlogin.java](https://commons.apache.org/proper/commons-net/examples/unix/rlogin.java), [rexec.java](https://commons.apache.org/proper/commons-net/examples/unix/rexec.java), [rdate.java](https://commons.apache.org/proper/commons-net/examples/unix/rdate.java), [fwhois.java](https://commons.apache.org/proper/commons-net/examples/unix/fwhois.java): inspect the exact client lifecycle and response parsing.

Telnet, TFTP, chargen, Finger, rlogin, rexec, and rshell can be unauthenticated or cleartext. Use only for explicitly required interoperability on an isolated, allow-listed path; do not expose them publicly or transmit secrets. Prefer encrypted protocol variants when Commons Net and the endpoint support them.
