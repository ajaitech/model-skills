# AWS official sources

Use the applicable AWS domain skill for account-specific execution. Resolve service, region, partition, API/CLI version, and installed SDK before browsing or changing resources.

| Need | Official URL | Crawl context |
|---|---|---|
| Service guides and APIs | https://docs.aws.amazon.com/ | Open only the exact service's current user guide and API reference sections. |
| Newly released capabilities | https://aws.amazon.com/new/ | Confirm region and availability, then verify operational syntax in service documentation. |
| AWS CLI syntax | https://docs.aws.amazon.com/cli/latest/ | Open the exact service command; confirm with local `aws <service> <command> help`. |
| SDK behavior | https://docs.aws.amazon.com/sdkref/latest/guide/overview.html | Follow the installed language SDK's developer guide and API reference linked from here. |
| Architecture review | https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html | Read only applicable pillars and service lenses; validate against the actual workload. |

Official domains: `aws.amazon.com`, `docs.aws.amazon.com`, and official `github.com/aws/*` repositories linked by AWS.
