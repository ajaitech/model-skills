# Laravel official sources

Match `composer.json` and `composer.lock` before selecting a documentation version. Open only the task-relevant page.

| Need | Official URL | Crawl context |
|---|---|---|
| Current release and support policy | https://laravel.com/docs/releases | Confirm the current supported major and PHP compatibility; do not turn this into an upgrade unless requested. |
| Framework syntax and features | https://laravel.com/docs | Select the installed major, then follow only the exact feature section. |
| Compatibility only: major-version migration | https://laravel.com/docs/upgrade | After the exact framework/API page, compare the installed and target majors across applicable breaking-change sections. |
| Class and method signatures | https://api.laravel.com/ | Select the installed major and verify the exact symbol signature. |

Official domains: `laravel.com`, `api.laravel.com`, and linked `github.com/laravel/*` source.
