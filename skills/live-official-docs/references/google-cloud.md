# Google Cloud official sources

Resolve the exact service, API version, region, installed client library, and `gcloud version`. Prefer GA interfaces for production.

| Need | Official URL | Crawl context |
|---|---|---|
| Service documentation | https://cloud.google.com/docs | Open the exact service's overview, API/reference, IAM, quotas, and operations pages needed. |
| gcloud CLI | https://cloud.google.com/sdk/docs | Open the exact command reference, then confirm with local `gcloud help`. |
| API conventions | https://cloud.google.com/apis/docs/overview | Verify versioning, resource names, pagination, retries, long-running operations, and errors. |
| Architecture | https://cloud.google.com/architecture | Select a directly relevant framework or reference architecture, then validate service-specific details. |
| Compatibility only: product changes | https://cloud.google.com/release-notes | After the service reference, filter to the exact installed-to-target interval for breaking or deprecated behavior. |

Official domains: `cloud.google.com`, `docs.cloud.google.com`, `developers.google.com`, and official `github.com/GoogleCloudPlatform/*` repositories.
