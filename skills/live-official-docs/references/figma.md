# Figma official sources

Identify REST API, Plugin API, Variables, Dev Mode, webhooks, OAuth, or MCP scope first. Confirm plan availability and token scopes without exposing credentials.

| Need | Official URL | Crawl context |
|---|---|---|
| Developer platform entry | https://developers.figma.com/ | Select only the relevant platform surface and access model. |
| REST API | https://developers.figma.com/docs/rest-api/ | Verify endpoint, scopes, rate limits, pagination, fields, errors, and availability. |
| Compatibility only: REST changes | https://developers.figma.com/docs/rest-api/changelog/ | After the endpoint reference, review changes and deprecations affecting the installed integration. |
| Plugin API | https://developers.figma.com/docs/plugins/ | Follow the exact manifest, API, UI, permissions, or publishing section. |
| Compatibility only: plugin updates | https://developers.figma.com/docs/plugins/updates/ | After the Plugin API page, check installed-to-target removals, migrations, and typing impact. |
| Figma MCP | https://developers.figma.com/docs/figma-mcp-server/ | Verify current client setup, capabilities, authentication, and limitations. |

Official domains: `developers.figma.com`, `figma.com`, `api.figma.com`, and official `github.com/figma/*` repositories linked by Figma.
