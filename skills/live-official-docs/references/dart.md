# Dart official sources

Match the SDK constraint in `pubspec.yaml`, `pubspec.lock`, and `dart --version` before using language features.

| Need | Official URL | Crawl context |
|---|---|---|
| Language syntax | https://dart.dev/language | Open only the relevant language feature and its versioning note. |
| Core library APIs | https://api.dart.dev/ | Verify the exact library, symbol, type, and deprecation state. |
| CLI and developer tools | https://dart.dev/tools | Follow the exact command page, then confirm with local `dart help`. |
| Package metadata | https://dart.dev/tools/pub/pubspec | Verify constraints, dependency syntax, platforms, and publish rules. |
| Compatibility only: SDK and language changes | https://dart.dev/changelog | After the language/API reference, check the installed-to-target range for breaking, removed, or versioned behavior. |

Official domains: `dart.dev`, `api.dart.dev`, `pub.dev`, and linked `github.com/dart-lang/*` source.
