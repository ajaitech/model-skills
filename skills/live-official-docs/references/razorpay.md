# Razorpay official sources

Identify live versus test mode, product, platform, installed SDK, and account capability. Never retrieve, print, log, or embed credentials while browsing.

| Need | Official URL | Crawl context |
|---|---|---|
| Product integration | https://razorpay.com/docs/ | Open the exact payment, checkout, subscription, payout, refund, or platform guide. |
| REST API contracts | https://razorpay.com/docs/api/ | Verify endpoint version, authentication, request/response schema, idempotency, errors, and webhooks. |
| Compatibility only: API changes | https://razorpay.com/docs/api/changelog/ | After the endpoint/SDK page, review changes affecting the installed integration and target capability. |
| MCP | https://razorpay.com/docs/mcp-server/ | Verify transport, authentication, supported tools, remote/local differences, and current integration page. |
| Official MCP source | https://github.com/razorpay/razorpay-mcp-server | Use releases, README, and source only when the docs require implementation-level confirmation. |

Official domains: `razorpay.com`, `api.razorpay.com`, and `github.com/razorpay/*`.
