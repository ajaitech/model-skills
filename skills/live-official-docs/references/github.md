# GitHub official sources

Identify GitHub.com versus Enterprise Server, API version, repository visibility, installed `gh` version, and required permissions before browsing or mutating.

| Need | Official URL | Crawl context |
|---|---|---|
| REST API | https://docs.github.com/en/rest | Open the exact resource and endpoint; verify API version, headers, permissions, pagination, and status codes. |
| GraphQL API | https://docs.github.com/en/graphql | Verify schema, connections, limits, deprecations, previews, and breaking changes. |
| GitHub Actions | https://docs.github.com/en/actions | Follow only the required workflow syntax, runner, permissions, security, cache, or deployment page. |
| GitHub CLI | https://cli.github.com/manual/ | Open the exact subcommand, then confirm with local `gh <command> --help`. |
| Compatibility only: platform changes | https://github.blog/changelog/ | After the exact GitHub Docs page, filter to the relevant product and interval. |

Official domains: `docs.github.com`, `cli.github.com`, `github.blog`, `github.com`, and `api.github.com`.
